# Just Do Eat

Application de commande de repas pour les stagiaires de l’OFPPT Ifrane.

- Interface en français, prix en dirhams marocains (DH)
- Palette de marque : #EDCA82, #097770, #E0CDBE, #A9C0A6
- Petit-déjeuner marocain et américain, sandwich thon, Chicken Bowl, pâtes et boissons
- Panier, code promotionnel de démonstration, créneaux de retrait et suivi des commandes
- Espace Admin, journal des événements et export de reçus
- Prototype local : les données persistent uniquement dans le stockage du navigateur de l’application
