# Just Do Eat

Application mobile-first de commande de repas pour les stagiaires de l'OFPPT Ifrane.

- Interface française, prix en DH
- Palette: #EDCA82, #097770, #E0CDBE, #A9C0A6
- Prototype local avec WebView Android
- Build APK via GitHub Actions

Consultez `README_BUILD_APK_FR.md` pour récupérer l'APK après le build.
